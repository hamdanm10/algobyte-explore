# algobyte-explore

YouTube Shorts for the **Algobyte Explore** channel (map animation, visual education, Indonesian narration), built with [Remotion](https://www.remotion.dev/).

- `npm i` to install, `npx remotion render <id> out/<slug>/<name>.mp4` to render.
- Workflow, conventions and docs: see `CLAUDE.md` and `docs/`.
- API keys live in `.env` (not committed).
